# Assets

This pack ships **no image files**.

The creator's original Beer Tracker has no beer photos, label art, or
venue images in its data model — a beer's record is its sourced component
breakdown and the user's verdict, and a venue's record is its confirmed
name, address, and coordinates. There is nothing visual to travel with
the pack, and nothing for a recreated space to generate or cache.

If a future version of the space adds label images, they would be fetched
per beer at lookup time (with sources), never shipped as pack assets.
